Usage: squirtl COMMAND

Trains an agent to play Pokémon Blue from the screen, through PyBoy and PyTorch.

╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ cite         Prints the footnote definition of each given key in the order   │
│              given, a blank line between two, for the body of an issue or a  │
│              pull request.                                                   │
│ evaluate     Evaluates the agent of each run at its last checkpoint, over    │
│              the episodes the run's settings record, beside the random       │
│              baseline under the same seeds, and writes each evaluation into  │
│              its run's directory, reading in place of playing any the run    │
│              already holds. The deep Q-network and PQN play at the epsilon   │
│              those settings record, and PPO takes its most likely action at  │
│              every step.                                                     │
│ stop         Writes the stop file into a training run's directory from any   │
│              shell, ending the run with a checkpoint and exit status 0, as a │
│              first interrupt does, at the end of its episode for the deep    │
│              Q-network and once a rollout's update ends for PQN and PPO.     │
│ train        Trains the agent --agent.algorithm names for the run's --steps  │
│              environment steps, headless unless --emulator.open-window is    │
│              set, logging a line per episode above a progress bar.           │
│ watch        Opens the emulator's window and plays back one episode the run  │
│              recorded, from the reset at the timer_div the run recorded for  │
│              it to the return the run recorded, at the sixty steps a second  │
│              the window paces.                                               │
│ write        Writes files the package declares into the checkout.            │
│ --help (-h)  Display this message and exit.                                  │
│ --version    Display application version.                                    │
╰──────────────────────────────────────────────────────────────────────────────╯
