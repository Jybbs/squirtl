Usage: squirtl watch [OPTIONS] [ARGS]

Opens the emulator's window and plays back one episode the run recorded, from   
the reset at the timer_div the run recorded for it to the return the run        
recorded, at the sixty steps a second the window paces.                         

The run is the one a directory holds, or one of the runs --release attaches,    
fetched into data/runs/ where it is missing there. --agent, --start, and --seed 
select it among the release's runs, and without them the release's recommended  
run plays.                                                                      

An episode that started along a demonstration plays the demonstration's presses 
up to its start first, and its return counts its own steps alone.               

Each of these exits 1 before the window opens:                                  

 • Both a directory and --release, or neither                                   
 • A directory holding no run, a release GitHub does not publish, or one        
   attaching no manifest                                                        
 • A download whose digest differs or whose tar does not unpack                 
 • A selection matching no run of the release, or more than one, each of which  
   it names                                                                     
 • An episode the run never recorded, or a cartridge the emulator refuses       

A console whose intro leaves a state of another digest than the run's exits 1   
before playing anything, and a playback reaching a return other than the one    
recorded exits 1 once it ends.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ DIRECTORY --directory  The run's directory under data/runs/.                 │
│ --episode INT          The episode to play, counting from 1, or none for the │
│                        last.                                                 │
│ --release STR          The tag of the release to read the runs from.         │
│ --agent CHOICE         The agent the run trained. [choices: dqn, ppo, pqn]   │
│ --seed INT             The seed the run's random draws derive from.          │
│ --start CHOICE         Where the run's training episodes start. [choices:    │
│                        bedroom, curriculum]                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
