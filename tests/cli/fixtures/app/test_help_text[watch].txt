Usage: squirtl watch [OPTIONS] DIRECTORY

Opens the emulator's window and plays back one episode the run recorded, or the 
demonstration a search found, from the reset at the timer_div recorded for it to
the return recorded, at the sixty steps a second the window paces. A search's   
return leaves out the novelty of each position.                                 

A directory holding no run, an episode the run never recorded, a search holding 
no demonstration, or a cartridge the emulator refuses exits 1 before the window 
opens, and a console whose intro leaves a state of another digest than the run's
exits 1 before playing anything. A playback reaching a return other than the one
recorded exits 1 once it ends.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  DIRECTORY --directory  The directory under data/runs/ of a run or a       │
│                           search. [required]                                 │
│    --episode INT          The episode to play, counting from 1, or none for  │
│                           the last, which a search refuses, since it holds   │
│                           one demonstration.                                 │
