Usage: squirtl pack [OPTIONS]

Writes each run docs/runs/ lists, and each demonstration those runs follow, into
dist/runs/ as the Zstandard tar a release attaches, beside the manifest.json    
listing each tar and its SHA-256 digest.                                        

Each run is read from its directory under data/runs/, and its tar holds its     
run.json, its episodes.jsonl, and a checkpoint holding the agent's weights      
alone, with no optimizer state and no replay memory. A search docs/runs/ lists  
packs as a demonstration, which no selection of the trained runs matches, and   
its tar holds no checkpoint. Every run.json packed names the cartridge          
data/rom.gb, and a run whose files are unchanged packs into the same bytes.     

Prints the folder holding the tars. Each of these exits 1 before any tar is     
written:                                                                        

 • A --recommended-run naming none of the trained runs                          
 • A run whose directory holds no record or no episodes, or a trained run's     
   holding no checkpoint                                                        
 • A run holding a line of episodes squirtl watch cannot read

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ --recommended-run STR  The name of the run a release plays where no          │
│                        selection names one. [default:                        │
│                        20261112T141501.166143Z]                              │
