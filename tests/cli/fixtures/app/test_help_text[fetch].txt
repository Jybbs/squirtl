Usage: squirtl fetch [OPTIONS]

Downloads the runs a release attaches and unpacks each into data/runs/, from the
release --release names or else the latest one.                                 

--agent, --start, and --seed select among the release's trained runs, and       
without them every run and each demonstration is fetched. A run data/runs/      
already holds downloads nothing. Each download shows a progress bar and is      
checked against the SHA-256 digests GitHub and the release's manifest record for
it before it is unpacked.                                                       

Logs the directory of each run. A release GitHub does not publish, one attaching
no manifest, a selection matching none of its runs, or a download whose digest  
differs or whose tar does not unpack exits 1.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ --release STR   The tag of the release to read the runs from.                │
│ --agent CHOICE  The agent the run trained. [choices: dqn, ppo, pqn]          │
│ --seed INT      The seed the run's random draws derive from.                 │
│ --start CHOICE  Where the run's training episodes start. [choices: bedroom,  │
│                 curriculum]                                                  │
╰──────────────────────────────────────────────────────────────────────────────╯
