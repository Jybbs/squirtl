Usage: squirtl evaluate [OPTIONS] DIRECTORIES

Evaluates the agent of each run at its last checkpoint, at the epsilon and over 
the episodes the run's settings record, beside the random baseline under the    
same seeds, and writes each evaluation into its run's directory, reading in     
place of playing any the run already holds.                                     

Prints as Markdown each run's measures, then each measure's interquartile mean  
across the runs with its 95% percentile bootstrap interval and the count of runs
behind it, then the probability that the agent beats its baseline, and the runs 
--against names where it names any, on each run's mean return.                  

A directory holding no run exits 1 before any evaluation, and a run holding no  
checkpoint, holding a damaged one, or reading a cartridge the emulator refuses  
exits 1, keeping the evaluations already written for the runs evaluated before  
it.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  DIRECTORIES --directories  The directory of each run whose agent to       │
│                               evaluate. [required]                           │
│    --against PATH...          The directory of each run of another agent to  │
│                               compare the first runs against.                │
╰──────────────────────────────────────────────────────────────────────────────╯
