Usage: squirtl cite KEYS

Prints the footnote definition of each given key in the order given, a blank    
line between two, for the body of an issue or a pull request.                   

A key that docs/references.bib does not declare, a file that fails to read, and 
a call naming no key each exit 1, printing no definition.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  KEYS --keys  The keys to print, each a lowercase surname and year.        │
│                 [required]                                                   │
╰──────────────────────────────────────────────────────────────────────────────╯
