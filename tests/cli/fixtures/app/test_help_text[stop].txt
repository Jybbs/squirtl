Usage: squirtl stop DIRECTORY

Writes the stop file into a run's directory from any shell, ending a training   
run at the end of the episode it is playing, or a search at the end of its      
iteration, with a checkpoint and exit status 0, as a first interrupt does.      

A directory holding no run exits 1.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  DIRECTORY --directory  The run's directory, under data/runs/ in the clone │
│                           it trains in. [required]                           │
╰──────────────────────────────────────────────────────────────────────────────╯
