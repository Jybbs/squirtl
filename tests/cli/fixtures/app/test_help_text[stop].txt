Usage: squirtl stop DIRECTORY

Writes the stop file that ends the run training in the directory given at the   
end of the episode it is playing, from any shell, where the run writes a        
checkpoint and exits 0 as it does on a first interrupt.                         

A directory holding no run exits 1.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  DIRECTORY --directory  The run's directory, under data/runs/ in the clone │
│                           it trains in. [required]                           │
╰──────────────────────────────────────────────────────────────────────────────╯
