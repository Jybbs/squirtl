Usage: squirtl stop DIRECTORY

Writes the stop file that ends the run training in the directory given at the   
end of the episode it is playing, where the run writes a checkpoint and exits 0 
as it does on a first interrupt, from any shell whose working directory holds   
the run under data/runs/.                                                       

A directory holding no run exits 1.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  DIRECTORY --directory  The run's directory under data/runs/. [required]   │
╰──────────────────────────────────────────────────────────────────────────────╯
